agent interfaces.

- orbs
- text response
- streaming text
- code block
- data table
- file diff
- inline citations
- comparison table

## Security / Operational Notes

The CLI can make registry requests and write component files into a target
project. Existing files are preserved unless overwrite behavior is explicitly
requested.

Pro functionality introduces an `AICSS_TOKEN` trust/credential boundary and
is not required for the admitted free capability.

## Overlap

There is overlap with general React/component-system resources already in the
stack, but AICSS has a sufficiently focused AI-interface primitive set to be
useful as a curated specialist rather than a general UI dependency.

## Decision

**PUSH — OPTIONAL / CURATED AI-UI SPECIALIST**

Admit the free MIT-licensed capability as an optional reusable component
source. Do not make it a core runtime dependency. Keep Pro/token-gated
functionality outside the baseline until separately justified and reviewed.
