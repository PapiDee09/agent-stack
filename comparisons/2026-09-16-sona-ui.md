## Capability

Sona UI exposes an agent-oriented shadcn registry workflow for discovering,
selecting, installing and validating UI components.

- provider-setup reference

## Architecture / Fit

The skill requires inspection of the consumer project's framework, React
version, styling entry, aliases and component conventions before installation.

Component selection considers:

- intended interaction
- use/avoid guidance
- accessibility
- motion
- dependencies
- reduced-motion behavior

The registry is treated as the source authority rather than asking an agent to
reconstruct existing components.

The skill explicitly requires the smallest useful installation set and says
not to rewrite a consumer's styling system merely to match Sona UI.

## Overlap

Sona overlaps with existing UI/component resources but adds a useful
agent-aware selection and validation contract.

It is complementary to AICSS:

- Sona: broader component selection/composition and consumer validation.
- AICSS: focused AI-interface primitives.

Neither needs to become a core application runtime dependency.

## Decision

**PUSH — OPTIONAL / CURATED UI SPECIALIST**

Retain Sona UI as an agent-aware component-selection and integration
capability. Install individual components only when justified by the consumer
project rather than importing the library wholesale.
